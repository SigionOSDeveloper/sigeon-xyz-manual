Chapter 1

Getting started

From a cold machine to a signed-in desktop.

Booting SigeonOS

Write the SigeonOS ISO to a USB stick or attach it to a virtual machine, then boot from it. The boot screen shows the pigeon logo, the release name, and a progress bar that walks through hardware initialisation, memory detection, PCI scanning, networking, Wi-Fi, audio, and finally the desktop.

SigeonOS is designed to run on modest hardware. The image is small (~7 MB) and the minimum RAM is around 64 MB, so it will boot comfortably on older machines and virtual machines.

First-boot setup

The first time you boot, SigeonOS runs a short setup wizard. You will be asked to:

  • Choose a language. English, Deutsch, Italiano, Russian, and Dansk are available. Changing the language later only affects SigeonOS-owned strings — your filenames, usernames, and messages are never translated.
  • Create a local account. Pick a username and a password. You can create up to eight local accounts.
  • Decide about telemetry. Off by default.
  • Optionally create a GoonMessage account. This is the online identity used by GoonMessage and GoonStore. You can skip it and add it later from Settings → Accounts.

Signing in

After setup you are taken to the login screen. Pick a profile, type your password, and press Enter. If you have more than one account, you can switch between them with the profile selector. Tab moves between the username and password fields.

Forgot your password? Local accounts are stored in the SigeonOS configuration journal. A factory reset from Settings → About will clear accounts and return the machine to first-boot setup, but it also clears your files, so it should be a last resort.

What is on the disk

SigeonOS uses a small filesystem called SigeonFS with an atomic two-bank snapshot journal. If the machine loses power mid-write, the previous committed snapshot is used on the next boot, so you should not lose already-saved files. Writable storage is on an optional ATA disk; without one, the filesystem runs in RAM and resets on reboot.

Chapter 2

The desktop

The top bar, the dock, the Control Center, notifications, and workspaces.

Top bar

The SigeonOS ball on the left opens the system menu. File, Edit, View, Window, Network, System, and Help menus sit beside it. The clock and Control Center button live on the right.

Dock

Pinned apps sit on the left, dynamic items appear as you open files, and the trash sits at the far right. Auto-hide, size, and pinning are all configurable.

Control Center

Wi-Fi, Bluetooth, Airplane Mode, Do Not Disturb, Night Shift, display brightness, volume, screenshot, screen recording, and a shortcut into Settings.

Notifications

Notifications appear in the top-right corner for a few seconds. Click the clock to open the Notification Center and see everything you have missed.

Workspaces

Up to seven virtual desktops. Each one has its own windows, desktop icons, and widgets. Open the workspace overview to switch or add a new one.

Desktop icons

Files in /SIGCOM/Desktop appear as icons. Drag to move, double-click to open, right-click for New Folder, New File, Rename, Delete, Pin to Dock, and Add Widget.

The SigeonOS menu

Clicking the ball in the top-left corner opens the system menu. It contains About This SigeonOS, Software Update, System Settings, Sigeon Account, Control Center, GoonStore, About Your System, Recent Applications, Force Quit App, Sleep, Restart, Shut Down, Lock Screen, and Log Out.

Control Center

The two-slider panel in the top-right corner adjusts display brightness and system volume live. The Wi-Fi, Bluetooth, Airplane, DND, and Night Shift tiles toggle immediately. Shot and Record buttons take a screenshot or start a screen recording; the Settings button closes the panel and opens Settings.

Notifications

Apps can post notifications through the in-kernel notification service. Each one carries the app name, an icon, and a message. Notifications are auto-dismissed after the duration set in Settings → Notifications, and the Notification Center keeps a scrollable history.

Workspaces

SigeonOS has up to seven workspaces. Each one keeps its own set of windows, desktop icons, and widgets, so you can keep, for example, a browser and messenger on desktop 1 and a terminal and text editor on desktop 2. Desktop 1 is permanent; the rest can be added and removed from the overview.

Open the overview with ShiftTabWSpace. Click a preview to switch, or use the plus tile to add a new workspace. The overview can also be opened from System → Control Center.

Chapter 3

Windows

How windows behave and how to move them around.

Anatomy of a window

Every SigeonOS window has a consistent chrome: a rounded Aero-glass frame, a coloured title bar, and three round buttons on the left — close (red), minimize (yellow), and zoom (green). The title bar shows the document name, or the custom instance name you have given the window.

Moving and resizing

  • Move: drag anywhere on the title bar.
  • Resize: drag the bottom-right corner of the window. The minimum size is roughly 180 × 100 pixels.
  • Zoom: click the green button, or use Window → Zoom. Zoom expands the window to fill the work area above the dock and below the top bar; clicking again restores the previous size and position.
  • Minimize: click the yellow button, or use Window → Minimize. The window shrinks into its dock icon with a short animation.
  • Close: click the red button, or use File → Close Window.

Focus and cycling

Clicking a window brings it to the front and gives it keyboard focus. Use Window → Cycle Windows to step through the open windows in the current workspace, or Window → Minimize All to clear the desktop in one go. Clicking a dock icon for an already-open app focuses its window; clicking it again minimizes it.

Close animations

Windows close with a short shrink-and-fade animation, which can be turned off in Settings → Appearance if you prefer the instant close.

Chapter 4

Finder & files

The SIGCOM tree, file operations, archives, and Trash.

The SIGCOM tree

SigeonOS keeps user-visible files inside /SIGCOM. The Desktop you see is the same folder as /SIGCOM/Desktop — there is no second copy anywhere, so a file on the desktop is a file in Finder and vice versa.

The Applications folder under /SIGCOM/Applications holds the built-in app launchers. /SIGCOM/boot holds the protected window and system components, which Finder deliberately does not treat as ordinary applications.

File operations

  • Open: double-click a file. Text opens in TxtWrench, images in Image Viewer, videos in Media Player, .pex executables run, and .html opens in SigeonWeb.
  • New Folder / New File: right-click in the content area, or in Finder's context menu.
  • Rename: right-click a file and choose Rename, or select it and press the shortcut.
  • Move: drag files onto a folder in the sidebar or into another Finder window.
  • Delete: right-click and choose Delete. The file goes to Trash, where it can be restored or the Trash can be emptied.
  • ZIP: right-click a folder and choose Compress to build a .zip archive, or right-click a .zip and choose Extract to unpack it.

File associations

SigeonOS decides which app opens a file by extension, then by content. A file with a .png or .gsv extension opens in Image Viewer; a file whose contents begin with the PNG signature opens in Image Viewer even if it has no extension. The full mapping lives in /SIGCOM/FileAssociations.cfg, which you can edit in TxtWrench.

Applications

Every built-in app and what it does.

Finder

Browse and organise files. Sidebar favourites, multi-select, drag-and-drop, rename, and archive support.

Terminal

A fast command shell one click from any desktop. See the Terminal chapter for the command list.

TxtWrench

A small text editor with undo, redo, find, word wrap, zoom, and a live line/column status bar.

Opens PNG and Sigeon GSV images. Zoom in, zoom out, or fit to the window.

Plays Sigeon SMPV video and PCM WAV audio. Compressed audio formats are listed but not yet decoded.

A large analog-style clock with the current time and date.

SigeonWeb

A small HTTP browser with an address bar, history, back/forward, and the built-in PexSearch landing page.

PexSearch

The local search page that opens inside SigeonWeb. Search works even when the external network is unavailable.

GoonStore

Browse, download, and upload files on the Sigeon Data Server. Files can carry a name, description, and icon.

GoonMessage

The Sigeon messaging app. Sign in with a Sigeon Account to chat with other people online.

Network Center

Live network status, Wi-Fi scan and connect, DNS editor, and a download speed test.

Weather

A small weather widget that refreshes over the network for a city you choose.

Settings

Eighteen panes covering Wi-Fi, displays, sound, keyboard, accounts, storage, and system actions.

Widget Gallery

Add, remove, resize, and configure desktop widgets. Widgets are per-workspace.

Trash

Chapter 7

PEX & Goon Code

Running executables and building simple GUI programs.

What a .pex file is

.pex is the one executable extension on SigeonOS. A .pex file is a PEX32 container: a short header followed by either native code or Goon Code bytecode, plus an optional string pool and a copy of the original source for the GUI renderer.

Double-click a .pex file in Finder, or select it and press Open, to run it. You can also drag a .pex onto the dock to pin it for quick access.

Permissions

When a PEX program asks for something it does not already have permission for, SigeonOS shows a permission prompt with the requesting access, a short description, and Allow / Disallow buttons. Tick Remember this to keep the decision for that program. The permission mask covers filesystem read, filesystem write, filesystem delete, network, UI, and hardware.

Goon Code

Goon Code is the small language that compiles to PEX32 bytecode. A Goon Code program describes a window with a title, a size, and a list of controls, then handles events raised by those controls. The kernel ships a Goon renderer that draws the window, handles clicks and keyboard input, and drives the VM.

Launch errors

If a .pex file cannot be started, SigeonOS shows an alert with the specific error code. The codes you are most likely to see are:

  • −1 — invalid PEX magic. The file is not a PEX32 container.
  • −2 — too small. The file is truncated.
  • −3 — out of memory. Not enough free RAM to load the image.
  • −4 — load failed. The container was valid but the payload could not be loaded.
  • −5 — invalid pointer. A program passed a pointer outside its own address window.
  • −6 — invalid opcode. The bytecode contains an instruction the VM does not recognise.
Sandboxing: native PEX programs run inside a fixed address window and can only read or write memory inside that window. Any attempt to reach outside it is reported as an invalid-pointer error rather than being allowed through.
Chapter 8

Networking

Wi-Fi, wired Ethernet, DNS, and the online apps.

Wired Ethernet

Intel e1000 and Realtek RTL8139 adapters are detected at boot and brought up automatically with DHCP.

Wi-Fi

Intel 8260, 8265, and 9260 wireless adapters are recognised. Wi-Fi Settings can scan and store network profiles.

Network Center

Four tabs: an overview, a Wi-Fi tab, a DNS editor, and a download speed test.

DNS

DNS servers come from DHCP by default. You can pin your own primary and secondary DNS in the DNS tab.

GoonStore & GoonMessage

Both apps use the Sigeon Data Server over HTTP. They need either wired Ethernet or a working Wi-Fi link.

Airplane Mode

Switches off wireless traffic in one click without touching the wired interface or your saved Wi-Fi settings.

Connecting to Wi-Fi

Open Settings → Wi-Fi. The page scans automatically and shows the networks the adapter can see. Pick a network to fill the SSID field, type the password, and press Join. The profile is saved so the network can be rejoined later without retyping the password.

Using the Network Center

  • Overview — link type, SSID, IPv4 address, gateway, and active DNS server.
  • Wi-Fi — scan for networks and connect to one from the list.
  • DNS — set a primary and secondary DNS server, or set both back to Automatic to use DHCP.
  • Speed — run a download speed test against the Sigeon test server.
Turning Wi-Fi off does not turn off the network. If a wired adapter is connected, SigeonOS keeps using it. Only Airplane Mode disables both radios at once.

System keybinds

The System Keybinds pane lets you record your own combination for a system action. Click a shortcut row and press the keys you want; SigeonOS captures the combination and saves it to the configuration journal. The default binding opens the workspace overview.

Factory Reset is on the About pane. It wipes local accounts, files, and settings, and returns the machine to first-boot setup. There is no undo.
Chapter 10

Customization

Wallpapers, accent colours, widgets, and the dock.

Wallpaper

Pick any .gsv file in Settings → Appearance. SigeonOS scales it to the framebuffer without distorting the aspect ratio.

Accent colour

Ten accent colours — Ocean, Mint, Sun, Berry, Slate, Violet, Ember, Forest, Crimson, and Indigo. The accent tints windows, menus, dock highlights, and the top bar.

Dock

Change the icon size and turn auto-hide on or off. Pinned apps stay on the left; dynamic items appear next to them as you open files.

Widgets

Open the Widget Gallery to add widgets to the current workspace. Each widget can be moved, resized, refreshed, or removed from its right-click menu.

Night Shift

Warm the display by reducing blue light. Toggle it from Control Center or Settings → Displays.

Desktop icons

Show or hide desktop icons from View → Show/Hide Desktop Icons, or from the desktop right-click menu.

Wallpaper files

SigeonOS wallpapers use the GSV format — a small RLE-compressed RGB565 image. The default wallpaper is /SIGCOM/Desktop/Background.gsv. To set a new one, drop a .gsv file into /SIGCOM/Desktop and choose it from Settings → Appearance.

Widgets per workspace

Widgets belong to the workspace they were added on. Add a clock widget to desktop 1 and a weather widget to desktop 2 and they will only appear where you put them. Removing a workspace moves its widgets, windows, and icons to desktop 1 rather than deleting them.

Chapter 12

Troubleshooting

What to do when something goes wrong.

Kernel panic

If the kernel hits a fault it cannot recover from, it shows a kernel panic screen: the error code, a short log line, a QR code, and a prompt to restart. The QR code links to the SigeonOS panic page with the code included, so you can look up the specific fault.

Press Enter on the panic screen to attempt a restart. If the machine restarts straight back into the same panic, note the code, boot from the ISO again, and report it.

Common error codes

Exception codes Reference
Code Meaning
EXC_DIVIDEA divide error in kernel code.
EXC_INVALID_OPCODEAn illegal instruction was executed.
EXC_DOUBLE_FAULTA second fault occurred while handling the first.
EXC_INVALID_TSSThe task-state segment is invalid.
EXC_SEGMENT_NPA segment that is not present was referenced.
EXC_STACKStack overflow or an invalid stack access.
EXC_GENERAL_PROTECTIONA general protection fault.
EXC_PAGE_FAULTA memory access to an unmapped page.
EXC_ALIGNMENTAn unaligned access where alignment was required.
MANUAL_CRASHThe developer crash chord was pressed.

If an app will not open

  • Check the file's extension. SigeonOS opens .pex files as executables, images in Image Viewer, video in Media Player, and everything else in TxtWrench.
  • If a PEX alert shows an error code, look it up in the PEX chapter — the codes are specific to what went wrong.
  • If the file appears blank in Finder, it may not have finished being written. Re-copy it and try again.

If the network is not working

  • Open Network Center → Overview to see whether a link is up and whether an IPv4 address has been assigned.
  • If the link is up but there is no IPv4 address, DHCP has not completed. Unplug and replug, or switch to a different network.
  • If DNS is failing but IPv4 works, set a public DNS server in the Network Center DNS tab and press Apply.
  • Check that Airplane Mode is off. Airplane Mode disables both wired and wireless traffic.

If the machine will not boot

  • Confirm the boot medium is set first in the firmware boot order.
  • If the ISO boots but SigeonOS freezes during the boot screen, try a machine with more RAM — the minimum is around 64 MB, but a little more gives the framebuffer and filesystem more headroom.
  • If you added a persistent ATA disk and the machine will not boot, disconnect it and boot without it. SigeonOS will fall back to a RAM filesystem, and you can reattach the disk afterwards.

Getting help

If you find a bug or need support, join the SigeonOS Discord at discord.gg/C6QfW357fw and post in #bug-reports. Include the error code and, where possible, a photo of the panic or alert screen.
